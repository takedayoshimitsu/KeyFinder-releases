# KeyFinder

Установщики KeyFinder для Windows. Этот репозиторий содержит описание и готовые выпуски приложения; исходный код KeyFinder здесь не публикуется.

## Скачать

[Последняя версия KeyFinder](https://github.com/takedayoshimitsu/KeyFinder-releases/releases/latest)

Скачайте файл `KeyFinderSetup-X.Y.Z.exe` и запустите его. Новая версия устанавливается поверх предыдущей с сохранением настроек и индекса.

## Обновления

Начиная с версии 2.3.0 приложение проверяет новые выпуски через GitHub. Ручная проверка: **Справка → Проверить обновления**. Учетная запись GitHub пользователю не требуется.

## Возможности

Локальный поиск по PDF, DOCX, XLSX, PPTX, OpenDocument, RTF и текстовым файлам; выбор форматов, индекс, фильтры и экспорт результатов. Документы пользователя не отправляются на GitHub.
